# ⚡ TIC: Transformer Inrush Current

Software for transformer and shunt reactor inrush current calculation.

### 📦 Download

➡️ [Download Installer (v1.2.2.0)](https://github.com/FedePorti/TIC-Installer/releases/download/v1.2.2.0/TIC.Setup.1.2.2.0.exe)

Run **TIC Setup 1.2.2.0.exe** and follow the wizard (English, Spanish or Portuguese). It installs over a previous version; if TIC 1.0 is installed, the installer removes it first. Your files in C:\TIC are kept.

⚠️ The installer is not digitally signed. When you download it, your browser may warn that the file is not commonly downloaded: choose **Keep**. When you run it, Windows may show **"Windows protected your PC"**: click **More info** and then **Run anyway**.

### 🛠️ Requirements
- Windows 10 or 11 (64-bit)
- Nothing else: .NET is included in the installer

### 📖 User manual
The user manual (English, Spanish and Portuguese) is installed with TIC and opens from **Help > User Manual**.

### 🆕 What's new in 1.2.2.0
- Input errors: a box no longer stays marked in red after the value is corrected, or after the value it is compared with changes (rated and saturation flux density, inner and outer diameter).
- The error mark is now a small circle on the top right corner of the box, and the error message is also shown as the tip of the box.

### What's new in 1.2.1.0
- Reactors: the core section is no longer shown or required, because the reactor calculation does not use it.
- User manual updated.

### What's new in 1.2.0.0
- Shunt reactors: new **Reactor** option, with its own model (the magnetizing current is not neglected and there is no remanence).
- Reactors are calculated at the rated and at the maximum operating voltage (Vmax), side by side, with their charts and an extra sheet in the Excel report.
- The rated inductance is shown, calculated from the power and the voltage, with Xair (Lair / Lnom) in its tip.
- New example: Example Reactor.
- User manual updated, with a chapter on reactors.
- Sharper notes on high-resolution screens.
- Fixes: the line current no longer shows NaN in a new file, and the horizontal scroll bar stays at the bottom of the window.
